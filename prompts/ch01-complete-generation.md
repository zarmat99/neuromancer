# Set di generazione finale — Capitolo 1

Versione 1.0. Le illustrazioni sono state generate senza testo; il lettering è
stato applicato separatamente da `scripts/build_ch01_complete.py`.

## Prompt base bloccato

> Tavola verticale di graphic novel cyberpunk noir, inchiostrazione dettagliata
> e colore pittorico controllato. Chiba retrofuturista industriale, superfici
> bagnate, tecnologia usurata, palette carbone/oliva/rosso neon/ciano. Rispetta
> esattamente le reference di volto, corporatura, outfit, oggetti e luogo
> fornite. Gutter neri netti, lettura occidentale. Nessuna parola, lettera,
> insegna leggibile, balloon, didascalia, watermark o bordo editoriale.
